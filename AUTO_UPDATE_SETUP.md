# Однократная установка автообновления

## Что будет обновляться

- Постоянный Apps Script-приёмник `ReceiverLoader.gs` загружает проверенный
  `receiver-release.json` и соответствующий неизменяемый файл кода из GitHub.
  Обычные обновления приёмника и правой панели не требуют нового развёртывания.
- Сервер проверяет `server-release.json` примерно раз в две минуты и обновляет
  только сборщик и четыре заранее определённых systemd-файла.
- Старый загрузчик `Loader.gs` продолжает обновлять основной код таблицы через
  `release.json`. Его заменять в этой установке не нужно.

SHA-256 проверяет целостность файлов. Источником доверия остаётся фиксированный
репозиторий `san7ek-rgb/wb-analytics`: его доверенные авторы могут публиковать
исполняемый код. Профиль WB, `.env`, себестоимость и ключи в выпуски не входят.

## 1. Apps Script — сделать один раз

1. Таблица → **Расширения → Apps Script**.
2. Заменить **весь код существующего CostReceiver.gs** содержимым файла
   **ReceiverLoader.gs** из репозитория. Не добавлять второй `doPost`.
   Отдельный файл `Loader.gs` и свойства скрипта сохранить.
3. Сохранить → **Развернуть → Управление развертываниями → изменить существующее
   веб-приложение → Новая версия → Развернуть**. Адрес остаётся прежним.
4. Выбрать функцию **wbInstallComparison**, выполнить один раз и предоставить
   разрешения. Это добавит меню сравнения, правую панель и цвета столбцов.
5. После успешного вызова запоминается проверенный выпуск. Если скачивание нового
   выпуска, его контрольная сумма или синтаксис некорректны, загрузчик попробует
   предыдущий проверенный код. Первой установке необходим доступ к GitHub.

Уже начавшийся обработчик не запускается повторно на другой версии: это могло бы
дважды записать данные. Ошибки исполнения требуют исправления или явного отката
указателя выпуска в GitHub. Новый код увидят следующие вызовы, обычно через несколько секунд;
уже открытая панель обновится после закрытия и повторного открытия.

## 2. Сервер — сделать один раз

Закрыть Firefox на сервере. Запустить от root `server/install-auto-updates.sh`,
передав SHA коммита. Установщик использует существующие профиль, окружение Python
и `.env`. Повторно вводить API-ключ или токен не требуется.

Установщик создаст `wb-auto-update.timer`, установит актуальный сборщик и очередь
сравнений, включит их таймеры. Если сейчас идёт сбор, установка кода откладывается
до свободного окна, автоматическая проверка повторяется каждые две минуты.
Обработчик сравнения держит управляющий запрос до 20 секунд и просыпается по
команде из панели. Без команды запросов в WB для сравнения нет. Профиль Firefox
во время ожидания не блокируется; между ожиданиями предусмотрена пауза 3 секунды.

Обновление проверяет размеры и SHA-256 каждого файла, синтаксис Python,
systemd-конфигурацию и загрузку модулей сборщика без обращения к WB/таблице.
Ошибка проверки сохраняет прежние файлы. Ошибка применения запускает восстановление
резервной копии. Отклонённый выпуск блокируется до публикации следующего.
Сетевой сбой не блокирует выпуск: скачивание будет повторено.

Истёкший вход WB, ошибка API или отказ Google не означают дефект установки:
автоматического отката по любой ошибке данных нет. Сбор за выбранный период всё
равно может потребовать повторного входа в WB.

Резервные копии кода и состояние: `/var/lib/wb-autoupdate/`. Ключ и профиль туда
не копируются. Системные обновления, новые зависимости Python, новые разрешения
Google, изменения самого постоянного загрузчика или обновляющего модуля могут
потребовать дополнительной однократной установки.

## Управление при необходимости

```bash
# Посмотреть результат автообновления, не выводя ключ:
journalctl -u wb-auto-update.service -n 15 --no-pager
# Вернуть предыдущие серверные файлы и заблокировать отменённый выпуск:
python3 /usr/local/lib/wb-autoupdate/auto_update.py --rollback
# Остановить только доставку новых версий:
systemctl disable --now wb-auto-update.timer
```

Установленный обновляющий модуль не даёт агенту произвольный доступ к серверу.
Он применяет опубликованные версии ограниченного набора файлов. Первый запуск
на вашем сервере и в Google проверяется после однократной установки; сама
публикация файлов в GitHub не является подтверждением установки.
