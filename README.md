# WB → Google Таблицы

Единая интеграция вкладки «Таблица конверсий». Постоянный загрузчик запускает
актуальный выпуск из этого репозитория. Терминал, Node.js и clasp пользователю не нужны.

## Одноразовая установка

1. В таблице открыть **Расширения → Apps Script**.
2. Заменить весь предыдущий код содержимым **Loader.gs**, сохранить.
3. Убедиться, что в свойствах скрипта сохранён **WB_API_TOKEN**.
4. Выбрать функцию **wbInstall**, выполнить и предоставить разрешения Google.
5. Вернуться в таблицу и обновить страницу. Появится меню **WB Аналитика**.

Идентификатор таблицы сохраняется только в свойствах скрипта. Ключ не передаётся
в GitHub. Не публиковать ключи, токены, OAuth-файлы или содержимое таблицы.

## Работа

- Ежедневное обновление между 04:00 и 05:00 МСК; ручное — через меню.
- Период по умолчанию — вчера; доступны последние 7 и 30 завершённых дней.
- Слева добавляется «Тип товара» с фильтром. Обувь и канцелярия объединяются
  словарём; остальные типы сохраняют категорию WB. Артикулы после вставки — в C.
- Существующий блок сдвигается в B:X и сохраняет свои формулы.
- Факты WB находятся в Y:AW: переходы, корзины, заказы, выкупы, выручка, остатки.
- Общие показы API воронки не предоставляет. В AO вносятся сопоставимые показы,
  в AP — точный текст периода из Y. Затем рассчитываются CTR и прогнозы.
- Прибыль оценивается по ручной марже «Прибыль с выкупа», после сдвига — J.
- Для ежедневного запуска используется только один пользователь-установщик:
  триггеры других пользователей невозможно удалить из его аккаунта.
- Другие вкладки не изменяются. Ошибки доступны в журнале Apps Script и
  свойстве WB_LAST_ERROR; время последнего успеха — WB_LAST_SUCCESS.

## Обновление кода

Изменить `src/Code.gs`, выполнить `python tools/build_release.py`, проверить
изменения, закоммитить исходник, новый файл `releases/` и `release.json`, отправить
в `main`. Старые файлы выпусков сохранять: они нужны для согласованной загрузки.
Загрузчик проверяет SHA-256 и получает новую версию при следующем запуске.
Изменения файлов в самом редакторе Apps Script при этом не происходят.

Код из этого репозитория исполняется с правами пользователя Google,
запускающего обновление. Доступ на запись в репозиторий должен быть только
у доверенных людей. SHA-256 проверяет целостность выпуска, а не защищает
от владельца репозитория с правом изменения кода. Не отключать защиту TLS.

Используется POST `/api/analytics/v3/sales-funnel/products`. Схема сверена
с опубликованной копией спецификации в
`salacoste/daytona-wildberries-typescript-sdk/wildberries_api_doc/11-analytics.yaml`;
официальный сайт документации был недоступен из среды разработки.
Запуск с ключом магазина выполняется только в пользовательском Apps Script.
